# GPX Studio - 路线规划工具

一个基于 PyQt5 的桌面应用，用于路线规划和 GPX 文件生成。采用模块化设计，易于维护和扩展。

## 功能特性

- 🌍 **地点搜索**：支持搜索起点、途径点和终点，显示前5个匹配结果
- 🗺️ **地图显示**：基于 Folium 的交互式地图，直观显示搜索结果和路线
- 📍 **智能定位**：浏览器定位 + IP 定位回退，自动获取当前位置
- 🚗 **路线规划**：使用 OSRM 路由服务规划最优路线，支持步行/骑行/驾车
- 📄 **GPX导出**：将路线导出为标准GPX格式文件，包含时间信息
- ⏰ **时间管理**：自动计算起始时间、经历时间和结束时间

## 模块说明

### 1. core（核心模块）
- `app.py`: 主应用窗口类 `GpxStudio`，整合所有功能模块

### 2. handlers（处理器模块）
- `geolocation.py`: 定位信号处理器，处理定位成功/失败事件
- `webengine.py`: 自定义 WebEngine 页面，拦截 JS 控制台消息

### 3. services（服务模块）
- `geocoding.py`: 地理编码服务，使用 Nominatim 进行地点搜索和反向地理编码
- `routing.py`: 路由规划服务，使用 OSRM API 进行路线规划
- `gpx_export.py`: GPX 文件生成和导出服务

### 4. ui（UI模块）
- `panels.py`: UI 面板工厂，负责创建各种界面组件
- `styles.py`: 集中管理 UI 样式定义

### 5. utils（工具模块）
- `map_renderer.py`: Folium 地图渲染工具，处理地图生成和显示
- `location_helper.py`: 定位辅助工具，提供 IP 定位等功能

## 使用方法

### 1. 启动程序

```bash
python main.py
```

### 2. 搜索和选择地点

- 在"起点"或"终点"输入框中输入地点名称（如：北京市）
- 点击"搜索"按钮或按回车键
- 中间面板将显示搜索结果列表
- 右侧地图会显示标记点
- 点击列表中的结果选择该地点

### 3. 添加途径点（可选）

- 在"途径点"输入框中输入地点名称
- 点击"搜索"按钮
- 右侧地图将显示前5个匹配的搜索结果（蓝色标记）
- 从左侧搜索结果列表中点击选择具体的途径点
- 可以添加多个途径点
- 使用"删除选中的途径点"按钮删除不需要的途径点

### 4. 设置终点

- 在"终点"输入框中输入地点名称
- 点击"搜索"按钮
- 右侧地图将显示前5个匹配的搜索结果（红色标记）
- 从左侧搜索结果列表中点击选择具体的终点
- 地图将更新显示选中的位置

### 5. 选择交通方式

- 在"交通方式"下拉菜单中选择：
  - 步行
  - 骑行
  - 驾车

### 6. 定位当前位置

- 点击右侧面板下方的"📍 定位我的位置"按钮
- 程序将自动获取您的当前位置（基于IP地址）
- 地图将自动定位到您的位置，并显示橙色标记
- 显示您的位置信息：纬度、经度、城市和国家

### 7. 设置时间

- 输入任意两个时间，第三个时间会自动计算：
  - 起始时间：路线开始的时间
  - 经历时间：预计行程时长
  - 结束时间：路线结束的时间

### 8. 规划路线

- 点击"规划路线"按钮
- 程序将使用OSRM路由服务计算最优路线
- 地图将显示规划好的路线

### 9. 导出GPX文件

- 点击"导出GPX"按钮
- 选择保存位置和文件名
- GPX文件将包含完整的路线信息和时间戳

## 注意事项

1. **网络连接**：程序需要网络连接来访问：
   - Nominatim地理编码服务
   - OSRM路由服务
   - IP定位服务（用于获取当前位置）

2. **搜索限制**：Nominatim服务有使用限制，请避免频繁搜索

3. **搜索技巧**：
   - 某些城市名可能需要加上省份名称（如：陕西省西安市）
   - 可以尝试使用英文搜索（如：Xi'an）
   - 程序会自动尝试多种搜索策略，提高搜索成功率

4. **时间计算**：时间计算基于简单的加减法，不考虑实际路况

5. **GPX时间戳**：导出的GPX文件中的时间戳基于设定的起始时间，按固定间隔生成

6. **定位精度**：当前位置定位基于IP地址，精度可能有限，仅供参考

## 常见问题

**Q: 搜索不到地点怎么办？**
A:
1. 尝试使用更具体的地址或地点名称（如：陕西省西安市而不是西安市）
2. 尝试使用英文搜索（如：Xi'an而不是西安市）
3. 确保网络连接正常
4. 稍后再试（可能是服务暂时不可用）
5. 某些城市名可能需要加上省份名称才能找到更多结果

**Q: 为什么搜索"西安市"只找到一个结果？**
A: 这是因为Nominatim服务对某些查询只返回最相关的结果。尝试使用"陕西省西安市"或"Xi'an"可以获得更多结果。程序会自动尝试多种搜索策略来提高成功率。

**Q: 路线规划失败怎么办？**
A: 检查网络连接，确保OSRM服务可访问。尝试选择不同的交通方式。

**Q: 导出的GPX文件在哪里打开？**
A: 可以使用任何支持GPX格式的软件打开，如Google Earth、Garmin BaseCamp等。

**Q: 如何修改已规划的路线？**
A: 重新选择起点、途径点或终点，然后再次点击"规划路线"按钮。
