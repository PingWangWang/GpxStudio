# GPX Studio

GPX Studio是一款基于PyQt5开发的开源路线规划工具，支持多种交通方式，可生成并导出GPX格式的路线文件。

## 主要功能

- **路线规划**：支持起点、终点及多个途径点的路线规划，可灵活调整路线顺序
- **多种交通方式**：支持步行、骑行、驾车等多种交通方式，满足不同出行需求
- **地图显示**：集成高德地图，提供直观的地图界面，支持缩放、平移等操作
- **路线信息展示**：显示详细的路线信息，包括起点、途径点、终点、预计时间、距离等
- **GPX导出**：将规划的路线导出为GPX格式文件，兼容主流GPS设备和导航软件
- **地理定位**：支持当前位置获取，可自动设置为起点或终点
- **地点搜索**：支持模糊搜索地点，快速定位目的地
- **配置灵活**：可自定义高德地图API密钥，支持不同缩放级别和地图样式
- **实时日志**：提供详细的操作日志，便于调试和问题排查
- **跨平台支持**：基于Python和PyQt5开发，支持Windows、macOS和Linux系统

## 技术栈

### 核心技术

- **Python 3.7+**：主要开发语言
- **PyQt5**：GUI框架，提供跨平台界面支持
- **PyQtWebEngine**：Web视图组件，用于显示地图
- **folium**：地图可视化库，用于生成交互式地图

### 功能库

- **gpxpy**：GPX文件处理，支持导入和导出GPX格式
- **requests**：HTTP请求，用于调用高德地图API
- **geopy**：地理计算库，提供地理编码和距离计算功能

### 架构设计

- **依赖注入**：使用依赖注入容器管理服务实例
- **服务接口**：定义清晰的服务接口，实现模块间解耦
- **模块化设计**：功能按模块划分，每个模块负责单一职责
- **信号槽机制**：使用PyQt的信号槽机制实现组件间通信

### 外部服务

- **高德地图API**：提供地理编码、路线规划、地图瓦片等服务

## 安装

### 环境要求

- Python 3.7+
- Windows 10/11 (支持Windows定位服务)

### 安装步骤

1. 克隆仓库

   ```bash
   git clone https://github.com/your-username/gpx-studio.git
   cd gpx-studio
   ```
2. 创建虚拟环境 (可选但推荐)

   ```bash
   python -m venv .venv
   .venv\Scripts\activate  # Windows
   ```
3. 安装依赖

   ```bash
   pip install -r requirements.txt
   ```
4. 配置高德地图API密钥

   - 访问 [高德开放平台](https://lbs.amap.com/) 申请API密钥
   - 方式一：直接编辑 `config/gaode_config.json` 文件，将API密钥填写到 `key` 字段
   - 方式二：启动应用后，通过界面配置（"工具" -> "高德地图配置"）

## 使用方法

### 1. 启动应用

```bash
python main.py
```

### 2. 搜索地点

- **输入搜索关键词**：在左侧搜索框中输入地点名称
- **选择搜索类型**：选择"起点"、"终点"或"途径点"
- **查看搜索结果**：在搜索结果列表中选择合适的地点
- **使用当前位置**：点击"获取当前位置"按钮，自动获取并设置当前位置

### 3. 规划路线

- **设置起点和终点**：通过搜索或地图点击设置起点和终点
- **添加途径点**：点击"添加途径点"按钮，可添加多个途径点
- **调整顺序**：可通过拖拽或按钮调整途径点顺序
- **选择交通方式**：从下拉菜单中选择步行、骑行或驾车
- **设置起始时间**：选择出发日期和时间
- **开始规划**：点击"规划路线"按钮，开始路线计算

### 4. 查看路线信息

- **地图显示**：右侧地图面板显示规划的路线和标记点
- **路线详情**：中间面板显示详细的路线信息（距离、预计时间等）
- **日志查看**：底部面板显示操作日志，便于了解系统状态

### 5. 导出GPX文件

- **导出路线**：路线规划完成后，点击"导出GPX"按钮
- **选择保存位置**：在文件对话框中选择保存位置和文件名
- **确认导出**：点击"保存"按钮，完成GPX文件导出

### 6. 配置和工具

- **高德地图配置**：通过"工具" -> "高德地图配置"菜单配置API密钥
- **关于**：查看应用程序版本和版权信息
- **日志级别**：可调整日志显示级别，便于调试
