# GPX Studio 架构优化方案

> 版本：v1.1 | 日期：2026-04-21 | 状态：阶段一~二已完成，阶段三进行中

---

## 一、现状分析

### 1.1 核心问题

| 问题 | 所在文件 | 影响 |
|------|----------|------|
| **上帝类** | `app.py`（5076行） | 职责混乱，难以单独测试和维护 |
| **UI 与逻辑耦合** | `app.py` 中直接操作 Qt 控件并调用业务逻辑 | 无法独立测试业务逻辑 |
| **巨型 `ui_updater` 字典** | `app.py._build_ui_updater()` | 回调地狱，依赖隐式约定 |
| **重复的右键菜单逻辑** | `_on_context_menu_set_start_new/end/waypoint` 三个方法几乎相同 | 违反 DRY 原则 |
| **DI 容器未全面使用** | `di.py` 存在但 `app.py` 仍手动 `new` 很多服务 | DI 形同虚设 |
| **坐标转换逻辑散落** | `app.py` 中大量内联坐标系转换代码 | 易出错，难以统一修改 |
| **内联 JavaScript** | `app.py` 中大段 JS 字符串 | 无法语法高亮、调试、复用 |
| **模块边界模糊** | `modules/` 和 `services/` 职责区分不清晰 | 循环依赖风险 |
| **缺乏接口抽象** | `services/interfaces/` 仅有 2 个文件，未完全覆盖 | 难以切换实现 |
| **`hasattr` 防御性代码泛滥** | 全文件大量 `hasattr(self, 'xxx')` | 说明初始化顺序不可控 |

## 二、优化目标

1. **`app.py` 瘦身**：将 5076 行拆解到 500 行以内，只保留组装和顶层协调逻辑。
2. **MVP/MVVM 分层**：UI 层不做业务决策，业务层不依赖 Qt 控件。
3. **完整接口抽象**：所有外部服务通过接口访问，支持热切换（高德↔OSM）。
4. **统一信号总线**：废弃 `ui_updater` 字典，改用 Qt 信号驱动 UI 更新。
5. **JavaScript 外置**：JS 代码移到独立 `.js` 文件，通过资源系统加载。
6. **可测试性**：业务逻辑能在无 Qt 环境下运行单元测试。

#### 1.1 提取 JavaScript 到独立文件

**当前问题**：`app.py` 中有 10+ 处大段内联 JS 字符串，例如 `on_zoom_in_clicked`、`on_zoom_out_clicked`、`on_zoom_fit_clicked`、`on_road_overlay_toggled`、`_on_context_menu_set_center` 等方法中的 JS 代码。

**操作**：

1. 新建 `src/modules/map/js/` 目录
2. 创建以下 JS 文件：
   - `map_zoom.js` — 缩放操作
   - `map_road_overlay.js` — 路网图层切换
   - `map_center.js` — 设置中心点
3. 在 `app.py` 中改为读取文件内容

```python
# 新建 src/modules/map/js_bridge.py
class MapJsBridge:
    """封装所有 JS 调用，避免内联字符串"""

    def __init__(self, map_view):
        self._map_view = map_view
        self._js_cache = {}

    def _load_js(self, name: str) -> str:
        if name not in self._js_cache:
            path = resource_path(f"src/modules/map/js/{name}.js")
            with open(path, encoding='utf-8') as f:
                self._js_cache[name] = f.read()
        return self._js_cache[name]

    def zoom_in(self):
        self._run(self._load_js('map_zoom'), 'zoomIn')

    def zoom_out(self):
        self._run(self._load_js('map_zoom'), 'zoomOut')

    def set_road_overlay(self, show: bool):
        js = self._load_js('map_road_overlay').replace('{{SHOW}}', str(show).lower())
        self._run_raw(js)

    def _run(self, js: str, func: str, callback=None):
        full_js = f"({js}).{func}();"
        self._run_raw(full_js, callback)

    def _run_raw(self, js: str, callback=None):
        page = self._map_view.page() if self._map_view else None
        if page:
            if callback:
                page.runJavaScript(js, callback)
            else:
                page.runJavaScript(js)
```

@dataclass
class Location:

    lon: float

    level: Optional[str] = None

@dataclass
class RouteWaypoints:
    """路线途经点集合"""
    start: Optional[Location] = None
    end: Optional[Location] = None

from typing import List, Optional, Tuple

@dataclass
class RouteAlternative:

#### 2.3 建立业务协调器（`domain/coordinators/`）

将 `app.py` 中的业务逻辑方法（非 UI 操作部分）迁移到协调器。

```python
# src/domain/coordinators/search_coordinator.py
from typing import Callable, List
from domain.services.geocoding_service import IGeocodingService
from domain.models.location import Location

class SearchCoordinator:
    """搜索业务协调器（无 Qt 依赖）"""

    def __init__(
        self,
        geocoding_service: IGeocodingService,
        on_results: Callable[[List[Location]], None],
        on_error: Callable[[str], None],
    ):
        self._geocoding = geocoding_service
        self._on_results = on_results
        self._on_error = on_error

    def search(self, query: str) -> None:
        try:
            results = self._geocoding.search_location(query)
            self._on_results(results)
        except Exception as e:
            self._on_error(str(e))
```

#### 2.4 建立 ViewModel 层（`ui/viewmodels/`）

ViewModel 持有 UI 状态，通过 Qt 信号通知 View 更新，不直接持有控件引用。

```python
# src/ui/viewmodels/search_viewmodel.py
from PyQt5.QtCore import QObject, pyqtSignal
from typing import List
from domain.models.location import Location

class SearchViewModel(QObject):
    """搜索视图模型"""

    results_changed = pyqtSignal(list)       # List[Location]
    loading_changed = pyqtSignal(bool)
    error_occurred = pyqtSignal(str)
    query_changed = pyqtSignal(str)

    def __init__(self):
        super().__init__()
        self._results: List[Location] = []
        self._is_loading = False
        self._query = ''

    @property
    def results(self) -> List[Location]:
        return self._results

    def set_results(self, results: List[Location]):
        self._results = results
        self.results_changed.emit(results)

    def set_loading(self, loading: bool):
        self._is_loading = loading
        self.loading_changed.emit(loading)
```

class GpxStudio(QMainWindow):
    """
    主窗口：负责组装各层组件，传递信号
    不包含任何业务逻辑
    """

    def __init__(self, splash_screen=None):

        self._build_domain()           # 初始化领域层
        self._build_ui()               # 构建 UI
        self._wire_signals()           # 连接信号

    def _build_infrastructure(self):
        """初始化基础设施（服务、配置、存储）"""
        self.container = DIContainer()
        self.geocoding = self.container.get(IGeocodingService)
        self.routing = self.container.get(IRoutingService)

    def _build_domain(self):
        """初始化业务协调器和 ViewModel"""
        self.search_vm = SearchViewModel()
        self.route_vm = RouteViewModel()
        self.search_coordinator = SearchCoordinator(
            geocoding_service=self.geocoding,
            on_results=self.search_vm.set_results,
            on_error=self.search_vm.error_occurred.emit
        )

    def _build_ui(self):

        self.map_view = MapView(self)
        self.search_bar = SearchBar(self.search_vm, self)
        self.route_panel = RoutePlanPanel(self.route_vm, self)

    def _wire_signals(self):
        """连接跨组件信号"""

        self.search_vm.results_changed.connect(self.map_view.show_search_results)

#### 3.2 统一坐标转换

将散落在 `app.py`（约 15 处）的坐标转换代码集中到工具类：

```python
# src/modules/geolocation/coordinate_transform.py（扩展）
class CoordinateTransform:

    @staticmethod
    def convert(lat: float, lon: float,
                from_system: str, to_system: str) -> tuple:
        """统一坐标转换入口"""
        if from_system == to_system:
            return lat, lon
        if from_system == 'GCJ-02' and to_system == 'WGS-84':
            return CoordinateTransform.gcj02_to_wgs84(lat, lon)
        if from_system == 'WGS-84' and to_system == 'GCJ-02':
            return CoordinateTransform.wgs84_to_gcj02(lat, lon)
        raise ValueError(f"不支持的坐标系转换: {from_system} → {to_system}")

    @staticmethod
    def ensure_system(lat: float, lon: float,
                      current: str, target: str) -> tuple:
        """确保坐标在目标坐标系中"""
        return CoordinateTransform.convert(lat, lon, current, target)
```

## 七、注意事项与风险

### 7.1 重构风险控制

- **每次只做一件事**，提交后验证功能正常再继续
- **不要同时改结构和改逻辑**，分两步走
- **优先提取，再删除原代码**，确保新旧并存可切换

### 7.2 PyQt5 特殊注意

- Qt 对象不能跨线程直接操作，ViewModel 信号必须通过 `Qt.QueuedConnection` 连接
- `QObject` 子类不能用 `copy.deepcopy`
- 析构顺序要注意，避免 C++ 对象已销毁但 Python 引用仍存在

### 7.3 保持向后兼容

- 重构期间保留 `ui_updater` 字典，逐步将其中的回调迁移到 ViewModel 信号
- 新旧两套路径可以并存，通过功能开关控制
